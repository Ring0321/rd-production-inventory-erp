# 瑞鼎生产库存订单 ERP

_基于 `ruoyi-vue-pro` 后端与 `yudao-ui-admin-vue3` 前端二次开发，用于管理生产炉层产出、成品入库、库存台账、订单差额、调拨、出库和日报表。_

---

## 项目结构

```text
rd-production-inventory-erp/
├── backend/   # ruoyi-vue-pro 后端与 yudao-module-rd-inventory 业务模块
├── frontend/  # yudao-ui-admin-vue3 前端与 src/views/rd、src/api/rd 业务页面
└── docs/      # 架构方案与详细开发计划
```

---

## 当前阶段

《ERP生产库存订单系统详细开发计划》第 1 至第 10 周已经完成。当前已形成生产入库、库存台账、订单差额、订单匹配、调拨、出库、日报、历史 Excel 迁移、库存看板、岗位权限、操作审计、性能验证、备份恢复和试运行部署闭环。

---

## 开发约束

- 不上传业务 Excel 原始文件
- 库存变化必须写流水，不能直接改余额
- 订单完成只改状态，不删除历史记录
- 前端页面必须保持现有 ERP 后台风格
- 所有列表必须服务端分页
- 大批量导入导出必须可追溯、可重试
