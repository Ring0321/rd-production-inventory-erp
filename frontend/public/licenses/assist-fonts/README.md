# Local Chinese Font

The runtime font is `/fonts/assist/NotoSansSC-Regular.ttf`, a static Regular 400
derivative of the pinned official Noto CJK source identified in provenance.json.
Its internal family name is Warehouse Assist SC. The filename is an integration
alias, not an upstream static release name.

Redistribute OFL.txt, NOTICE.txt and provenance.json with the font. Original
copyright, reserved-name and license statements are retained. No proprietary
operating-system font is bundled. Verification tools and development evidence
are not part of this public asset directory.
