## 1. 岗位权限模型

权限脚本：`backend/sql/mysql/rd_inventory_week10_permissions.sql`。脚本可重复执行，保留内置系统管理员，并为租户 1 建立五类 RD 业务角色。

| 角色 | 角色编码 | 主要职责 | 有效权限数 |
| --- | --- | --- | ---: |
| 瑞鼎库管 | `rd_warehouse` | 入库、出库、调拨、库存与日报 | 34 |
| 瑞鼎生产录入 | `rd_production` | 生产产出录入、预检和查看 | 11 |
| 瑞鼎订单专员 | `rd_order` | 销售订单、库存匹配和完成跟踪 | 18 |
| 瑞鼎审核员 | `rd_auditor` | 库存调整、调拨确认和撤销审核 | 16 |
| 瑞鼎只读管理 | `rd_readonly` | 看板、台账、订单、报表和导出 | 19 |

验收脚本：`scripts/security/Test-RdPermissions.ps1`。

- 五个临时用户均能登录并取得对应角色权限。
- 每个角色的允许接口均返回业务码 `0`。
- 每个角色的越权接口均返回 HTTP 业务码 `403`。
- 测试完成后自动删除临时用户、角色关联、令牌、测试日志和 Redis 权限缓存。

## 2. 业务操作审计

审计日志统一写入 `system_operate_log`，记录操作类型、子类型、业务编号、动作说明、操作人、成功状态、请求地址、时间和租户。

| 模块 | 已记录动作 |
| --- | --- |
| 生产产出 | 新增、修改、作废、转入库存 |
| 库存批次 | 手工期初录入、库存调整 |
| 销售订单 | 新增、修改、取消、指标重算 |
| 订单匹配 | 人工匹配、自动匹配、取消匹配 |
| 调拨单 | 新增、修改、确认、取消 |
| 出库单 | 新增、修改、确认、取消 |
| Excel 导入 | 上传预检、确认导入 |
| 库存日报 | 指定日期范围重建 |

批量 Excel 确认不会为每一行库存重复生成一条“手工期初录入”日志，只记录导入任务级日志，避免大文件导入造成日志膨胀。

验收脚本：`scripts/security/Test-RdOperationLogs.ps1`。

实际执行“期初库存、库存调整、销售订单、库存匹配、出库单、确认出库”后：

| 检查项 | 结果 |
| --- | ---: |
| 操作日志总数 | 6 |
| 成功日志数 | 6 |
| 覆盖操作类型 | 4 |
| 关联业务编号 | 3 个唯一数值，库存与出库自增编号恰好相同 |

四类日志分别为 `RD 库存`、`RD 销售订单`、`RD 订单匹配`、`RD 出库单`。测试结束后，库存、订单、匹配、出库、流水、日报和审计测试数据残留均为 0。

## 3. 前端异常提示

- 500 错误优先显示后端返回的业务原因，不再统一覆盖成“系统异常”。
- 网络错误提示用户确认 ERP 服务是否启动并检查网络。
- 超时错误提示稍后重试或缩小查询范围。
- 同一时间出现的相同错误使用 Element Plus `grouping` 合并，避免登录页连续弹出多条相同提示。
- 页面确认框和导出确认的取消操作继续静默处理，接口错误仍由统一拦截器展示。
