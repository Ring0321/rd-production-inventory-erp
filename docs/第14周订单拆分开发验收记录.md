# 第14周订单拆分开发验收记录

## 完成内容

- 新增订单拆分规则及炉层分配明细，可按客户、型号配置装炉量、成品率、炉层固定量和分配顺序。
- 新增销售订单拆分执行流程，支持按订单应入数量试算、保存拆分结果、人工修正、确认和取消。
- 拆分结果独立保留试算数量、人工修正数量及最终数量，历史规则变更不追溯修改已确认结果。
- 新增生产炉层产量绑定，只有已确认且客户、型号、炉号、炉层一致的生产记录可绑定拆分结果。
- 销售订单产额拆分为人工产额、拆分绑定产额和实际总产额，订单差额统一按应入数量减实际总产额计算。
- 拆分产额由有效生产绑定重新汇总，解绑或作废后自动回算，避免重复累加；销售订单已完成数量、调拨后差额和订单状态同步按“实际产额 + 调入 - 调出”回算。
- 生产产量增加确认动作、版本校验和行锁；已绑定记录不得修改或取消。
- 新增订单拆分页面、规则配置、拆分试算、人工修正、生产绑定和结果详情，并接入销售订单快捷入口。
- 新增订单拆分菜单、八项操作权限及对应角色授权，原有销售订单和生产产量接口保持兼容。

## 数据与安全约束

- 拆分确认本身不产生库存、不创建包码，也不直接增加销售订单实际产额。
- 生产记录与拆分结果建立有效绑定后，才计入拆分绑定产额。
- 同一生产记录只能存在一条有效绑定；绑定、解绑和产额回算在同一数据库事务内完成。
- 现有销售订单的历史实际产额迁移为人工产额，拆分绑定产额初始化为零。
- 全新基线和幂等升级脚本均包含拆分表、索引、菜单及权限，升级不修改原有库存业务数据。
