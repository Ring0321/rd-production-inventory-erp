# 五项开源创新复用实施规格

## 授权与边界

2026-10-15，用户授权按已调研的五个方向对应复用。基线 c0ead42，原分支、Spring Boot/MyBatis/MySQL、Vue3/Element Plus 和 Three.js 不变。登录后的“作业智助”提供配吨、时间回放、本地识别、布局编辑、标签模板五个实际入口，不以安装依赖冒充完成。原 C5-R2/R3、C6 和真实设备/现场验收仍开放，真实 GLM 不启用且不扩大外发范围。原包码、客户资料及单据保留；仓管扫码/选位/最终确认，司机只搬运/装车/反馈，整车任务不拆组。

## 结果与验收

- REUSE-1 配吨：实际复用 OR-Tools Java CP-SAT，从原提货单及可用包件读取候选，不信任前端自报重量/客户/质检；按实际净重、客户/型号、占用条件返回清单、总重、差额和求解状态。无解/超时不能称最优。只读计算，不锁货、不派单、不写库存。检查尾包/精度/无解/占用/权限及真实提货单端到端。
- REUSE-2 回放：实际复用 vis-timeline 展示原库存流水及逐包追溯事实，区分登记时间/业务日期，关联精确库位及原单据。无历史证据则未知，不以当前库位倒推、不模拟叉车路径。检查实际事件、排序/时区/缺失、权限、零业务写及桌面/小屏。
- REUSE-3 OCR：实际复用 PaddleOCR，自托管受限服务，由原后端鉴权代理调用；本地图片/PDF识别，原文/候选字段对照、人工改正和草稿导出，不自动创建正式单据。原件和全文不发 GLM；限制类型/大小/页数/并发/超时，拒绝任意URL/路径/远端服务地址。检查合成非敏感样本真实推理、恶意文件/权限/不可用及浏览器上传；无模型时必须明确不可用。
- REUSE-4 布局：实际复用 Konva/vue-konva，区域/通道/绑定真实库位ID的布局编辑、草稿/服务端保存/版本冲突/发布。只改变展示配置，不改库存/库位/原行列，不允许跨仓绑定。检查拖动/保存/刷新/冲突/发布、库存不变及小屏。
- REUSE-5 模板：实际复用 pdfme，限定字段/本地字体、尺寸/布局编辑、服务端版本/发布、真实包件预览/PDF。包号和二维码来源不可覆盖，首次/补打仍走原审计接口和补打原因/权限。检查实际PDF/中文/二维码还原、配置版本、打印记录和权限。
- REUSE-6 集成：五项角色入口、身份变更清空/迟到响应、无外站业务数据、原Web/PDA/3D/业务全景回归；限定源码/秘密/许可审查、正式构建和浏览器证据。每项仅按实际证据划掉，不把本地当现场验收。

## 配置与模块合同

主任务负责 `/operations-assist`、路由/权限/导航、共享API、布局/模板配置服务、时间回放、依赖锁和最终集成。支持独占 `assist/weight/` 与后端 weight、`assist/ocr/` 与后端 documentocr/`tools/document-ocr/`、`assist/layout/` 与 `assist/templates/` 三个隔离写集，不改运行库/凭证或共享路由/锁文件。

展示配置接口：`GET /rd/visual-document/get?kind=LAYOUT|LABEL&scopeId=...`；`POST /save` 输入 `{kind,scopeId,expectedVersion,content}`；`POST /publish` 输入 `{kind,scopeId,expectedVersion}`。返回 `{kind,scopeId,version,draft,published,publishedVersion,updatedAt}`。核对原表后修正：原仓库按 warehouseCode 管理、没有独立仓库ID；LAYOUT scopeId为原仓库编码字符串，LABEL为字符串 `GLOBAL`。不杜撰仓库实体ID。乐观版本必填，每次保存/发布保留修订记录；不改任何库存业务表。

LAYOUT content：`{schemaVersion:1,warehouseCode,width,height,elements:[{id,kind:'LOCATION'|'AISLE'|'ZONE',locationId?,x,y,width,height,label}]}`。坐标为有限正画布单位，LOCATION绑定本仓库且不重复的真实库位ID，其他类型不绑定库位；拒绝URL/HTML/脚本/任意属性。LABEL content：`{schemaVersion:1,name,widthMm,heightMm,fields:[{key,x,y,width,height,fontSize}]}`；白底黑字，字段白名单 `brand,packageCode,qrCode,customerName,productModel,furnaceNo,furnaceLayer,packageWeight,productionDate`；包号/二维码各恰一个。模板不存实际客户/包件值，不接收原PDF/图片/远端字体；前端转换为受控pdfme schema。

布局读用原库位查询权，保存/发布用原库位修改权。模板读用包件查询权，保存/发布仅原管理员；打印复用原标签打印/补打权。所有权限后端独立验证；数据按当前身份/权限代次保护。预览与实际保存/发布/打印明确区分。
