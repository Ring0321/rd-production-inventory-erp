# 岗位操作培训手册

## 1. 通用要求

所有业务人员使用个人账号，不共用管理员账号。操作前确认右上角租户、业务日期和当前页面；业务已确认后不得通过数据库直接修改或删除，应使用取消、冲销、调拨或库存调整，并填写原因。

## 2. 生产录入岗

1. 在“生产管理”录入生产日期、货位、客户、型号、生产炉号、所在炉层、产量和单包重量。
2. 核对客户、型号、炉号、炉层四个维度后保存。
3. 产出未入库前可以修改或作废；转入库存后不得直接改产量。
4. 转入库存会生成库存批次和入库流水，需到库存台账确认数量。
5. Excel 历史数据必须先预检，处理错误行后再确认导入。

## 3. 库管岗

1. 每日先核对期初、前一日结存和现场实物。
2. 入库后按货位、客户、型号、炉号、炉层检查库存批次。
3. 库房数量、锁定数量和可用数量分别表示实物余额、订单占用和可继续匹配数量。
4. 库存调整必须选择调增或调减并填写原因；调减不得超过库房数量。
5. 出库前检查销售订单、匹配记录和出库数量；确认后系统扣减库存并写出库流水。
6. 每日结束前核对“每日出入库统计”的入库、出库、调入、调出、退货和净变化。

## 4. 订单专员

1. 销售订单录入订单号、日期、客户、型号、应入数量和实际产额。
2. 系统计算 `差额 = 应入数量 - 实际产额 - 调入数量 + 调出数量`，以页面显示为准。
3. 匹配库存时优先选择客户和型号一致、日期较早的可用批次。
4. 自动匹配只占用可用库存，不直接出库；取消匹配会释放锁定数量。
5. A 订单不足时可从 B 订单相关库存调拨，确认调拨后两张订单差额同时重算。
6. 出库累计达到调整后应完成数量时订单自动关闭，不手工删除订单。

## 5. 审核岗

1. 重点审核库存调整、调拨确认、调拨取消、出库取消等高影响动作。
2. 审核客户、型号、来源订单、目标订单、库存批次、数量和原因是否一致。
3. 通过“系统管理 / 操作日志”按操作类型和业务编号追溯操作人、时间、请求和成功状态。
4. 发现异常先暂停后续业务，保留业务编号和截图，由管理员查询库存流水和审计日志。

## 6. 只读管理岗

只读人员用于经营查看和盘点复核，可访问库存看板、台账、订单、报表和导出功能，不具备新增、修改、确认、取消和调整权限。导出文件仍属于企业业务数据，不通过个人网盘或非授权聊天工具传播。

## 7. 管理员

1. 创建用户并只分配完成岗位所需的最小角色。
2. 人员转岗或离职当天停用账号，不能只修改昵称。
3. 每日检查服务健康、磁盘空间和备份结果，每月执行恢复演练。
4. 不在业务高峰执行升级、索引变更或批量导入。
5. 故障处理顺序为保留现场、停止写入、备份、隔离验证、恢复服务、补录审计说明。

## 8. 每日交接清单

| 项目 | 交接内容 |
| --- | --- |
| 生产 | 当日产出、未入库、已作废记录 |
| 库存 | 入库、出库、调拨、调整、账实差异 |
| 订单 | 新增、待匹配、待出库、已完成、异常差额 |
| 导入 | 预检任务、错误行、已确认任务 |
| 系统 | 失败操作、权限异常、备份状态、待处理故障 |
