## 5. 发布与运维交付

已提供以下交付件：

- `deploy/trial/`：MySQL、Redis、Spring Boot、Nginx + Vue 3 的试运行 Compose 部署。
- `deploy/trial/compose.runtime.yaml`：发布 ZIP 使用的无源码运行时部署。
- `scripts/backup/`：备份、恢复和隔离恢复演练脚本。
- `scripts/release/`：后端 JAR、前端静态资源、数据库脚本、部署文件和文档的一键发布包脚本。
- 《试运行部署、备份与回滚手册》：部署、升级、回滚、监控和容量要求。
- 《岗位操作培训手册》：库管、生产、订单、审计和只读岗位操作边界。

最终发布包从已推送的干净 Git 提交生成，包旁的 `.sha256` 文件作为传输和部署校验依据；`releases/` 与 `backups/` 均不提交 Git，避免将大文件和业务备份上传到远程仓库。

发布包复验过程中未调用 Maven、Node.js 或 pnpm，仅从包内 JAR 和静态资源构建运行时镜像；管理员登录和库存看板接口均返回 `code=0`。
