# 第13周库存盘点开发验收记录

## 完成内容

- 新增按单货位执行的库存盘点单，覆盖新建、冻结快照、扫码实盘、提交、双人审核、差异调整、关闭和取消。
- 盘点冻结绑定具体盘点单，关闭或取消时仅释放本单持有的货位锁。
- 盘亏包保留为 `STOCKTAKE_MISSING`，以后在原货位找回时可作为盘盈恢复。
- 盘盈、盘亏按包生成幂等库存流水，并回填盘点明细对应流水号。
- 货位冻结统一拦截入库、出库、调拨、订单占用和手工库存调整。
- 调拨按具体包码迁移库存批次和客户归属，并使用关联表保留原包码以支持准确撤销。
- 盘点单记录业务制单人，制单人或提交人均不得审核；状态动作强制版本校验，提交后不得由操作岗取消。
- 新增库存盘点列表、扫码窗口、详情及差异页面，并完成移动端适配。
- 新增盘点菜单、八项操作权限及库房管理岗、库房操作岗、审计岗、只读岗授权。
