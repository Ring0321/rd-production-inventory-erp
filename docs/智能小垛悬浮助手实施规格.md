# 智能小垛悬浮助手实施规格

日期：2026-10-20。用户希望 ERP 页面过多时可通过左下角常驻的“智能小垛”找页面、查内容及提问。

## 本轮范围

- 原 ERP Layout 内增加左下角悬浮入口；正常业务页面间切换保持当前对话，登录、公开护照和独立 PDA 页面不另挂助手。
- 紧凑非模态对话窗，支持展开/收起、清空、取消查询、键盘输入、页面直达、当前页面语境；320/390/1440 尺寸适配，不覆盖既有确认弹窗。
- 导航只从当前账号的可见菜单取得；跳转前再核对当前权限和目标，拒绝隐藏、外链、动态参数和任意生成路径。别名支持“产品”“货位图”“入库”“装车”等业务叫法。
- 本地操作知识覆盖生产、质检、批次代表扫码、入库、库位、整车出库、司机边界、离线采集与 AI 边界；知识注明来源，不把固定规则冒充大模型生成。
- 明确查询时复用已有鉴权 GET：库存看板汇总、仓储空间登记数量、单包内部追溯/扫码问货上下文。显示数据范围和查询时间；未知不填零，查不到不声称货物不存在，不从炉层推断货位层级。
- 库存看板是其接口所定义的汇总范围，不冒充当前仓库筛选；仓储登记可按当前页面明确选定的仓库过滤。单包结果必须绑定精确包码。
- 不读取表单/剪贴板/附件，不自动跳页或执行业务写入；提交、放行、过账和搬运职责不变。司机不新增全仓、包件及扫码权限。
- 悬浮窗采用本地意图识别、规则知识及原 ERP 实查；不外发用户问句、客户、包码、库位或会话，不开放任意 SQL/工具调用。用户追加的 DeepSeek 受控分析接入原内部包件页，不将悬浮窗称为任意模型聊天。
- 对话仅驻留内存，限制长度和条数。退出、账号/权限/租户变化时立即清除并取消显示旧请求结果；取消/清空/新会话使用单调代次拒绝迟到响应，不持久化业务明细。

## 用户追加的 DeepSeek 配置

2026-10-20 用户确认所提供凭据属于 DeepSeek，并选择普通对话模型。凭据通过 SSH 标准输入只保存到 ERP 专属 root-only 私密待配置文件，不进入代码、Git、前端、截图或证据。官方 `GET /models` 实际鉴权通过，返回 `deepseek-flash` 和 `deepseek-v4-pro`；普通对话按 `deepseek-flash`、非思考模式准备。

用户随后确认 20 元/月。现已完成 DeepSeek 固定接口适配、共享月度预算和独立云端发行，普通模型 `deepseek-flash` 显式关闭思考。原内部包件页“包码问答 → 请求整理”真实调用成功一次，返回 252 tokens；原请求核对、刷新及独立浏览器恢复不再次调用模型。自有 Redis 重启后，预算仍为 1 次、保守预留 0.10 元，原成功回执可读；这不是平台实际扣费。每月最多 200 次新请求，同时每天 30 次、每人每分钟 2 次，失败不退回预留，2026-11-19 后需重新核价。

仅外发状态与汇总白名单，模型只能排序 ERP 提示键。悬浮窗仍负责本地找页、知识及真实查询，可引导进入内部包件页；不把它描述为已接通自由聊天。GLM 保持关闭，密钥与私密备份不归档。详细证据见《DeepSeek云端受控接入验收记录-20261020》。
