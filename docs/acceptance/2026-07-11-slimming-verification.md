# ERP 深度瘦身验收记录

日期：2026-07-11

## 验收结论

瑞鼎生产库存订单 ERP 已完成平台瘦身、固定租户改造、品牌统一、干净数据库基线、权限矩阵、备份恢复和双部署模式验证。所有验证均在隔离环境执行，未连接旧 9000 环境、生产数据库或原始 Excel。

## 构建与测试

- Temurin JDK 17：`mvn -q -pl rd-erp-server -am clean test` 全量通过。
- Temurin JDK 21：`mvn -pl rd-erp-server -am -DskipTests clean package` 打包通过。
- 前端：`pnpm ts:check` 与 `pnpm build:prod` 通过，生产构建转换 2894 个模块。
- 前端源码由整改前 766 个文件降至 339 个文件，减少 55.7%。
- 发布脚本强制执行 `clean package`，避免已删除模块的旧 `target` 文件进入 JAR。

## 数据库与权限

- MySQL 8.4 干净基线初始化成功，共 43 张表、固定租户 1、一个管理员和五类 RD 角色。
- 幂等升级脚本可在精简基线上重复执行，RD 业务数据不变。
- 五类角色均完成允许/拒绝接口验证：允许接口返回业务码 `0`，越权接口返回 `403`。
- 五类角色均包含 `rd:dashboard:query`，登录后可读取 ERP 工作台看板。
- 权限测试创建的临时用户、令牌、日志和 Redis 缓存均已自动清理。

## 运行与浏览器

- 源码 Compose 项目 `rd-erp-slim-verify`：MySQL、Redis、后端、前端四容器健康。
- 无源码运行时 Compose 项目 `rd-erp-runtime-verify`：从发布 ZIP 解压后四容器健康。
- 账号登录、认证能力、权限信息和 `/rd/dashboard/overview` 均返回成功。
- 已删除租户管理接口返回 `404`。
- 桌面视口 1440x900 与移动视口 390x844 无横向溢出，浏览器控制台无 error/warn。
- 登录页不显示租户、注册、二维码、手机登录、找回密码及未配置的认证入口。
- 登录后只显示 ERP 工作台、瑞鼎库存和精简系统管理菜单。

## 备份与安全

- 隔离库备份 SHA-256 生成成功，恢复得到 43 张表。
- 10 张关键业务与权限表的源库/恢复库行数逐表一致。
- Gitleaks 8.30.1 工作区扫描约 46.71 MB，未发现密钥。
- Gitleaks 完整 Git 历史扫描 32 个提交、约 11.66 MB，未发现密钥。
- API 访问日志不再记录登录请求体或密码。
- 上游宣传 Banner、文档链接和无关模块清单已从后端自动配置中删除。

## 本轮修复

1. 缩小 Spring 扫描范围并补充 RD Mapper 扫描，避免 Bean 冲突和 Mapper 缺失。
2. 管理员首次密码初始化固定在租户 1 内执行，并避免生成无用户上下文的操作日志。
3. 登录密码长度上限统一为 64，消除前后端规则冲突。
4. 修复权限指令在 Pinia 激活前读取 Store 导致的生产页面白屏。
5. 修正五类角色 ID、看板权限、Redis 密码和隔离数据库参数。
6. 修正升级脚本对已移除租户字段的依赖，恢复幂等执行。
7. 修正发布脚本未清理旧构建目录导致已删除 Kafka 类进入运行时 JAR的问题。

## 外部事项

短信、钉钉、微信等历史疑似凭据的实际轮换必须在对应第三方控制台完成。仓库、历史和当前发布内容已通过本地密钥扫描，但第三方控制台轮换仍需具备企业账号权限的管理员执行并留档。
