## 5. 发现并修复的问题

1. SQL parser 首次重组拆开了 MySQL `DELIMITER ;;`，升级停止；当时仅为新实例未导完的空业务库。更正为 token 定位删除客户种子、其余字节保留后重新导入。
2. Windows mysqldump 的中文筛选导致 4 张表未导出；指令返回 0 不代表有数据。改为 ASCII ID 白名单导出、解析每表 INSERT 数量后，仅补齐空缺的库存批、销售单、提货单、客户型号表，已有包件/任务/流水不覆盖。
3. 新随机密码超出原修改密码接口 16 位上限、带下划线的登录名不符合原规则；仅调整新云端账号生成策略，未放宽原 ERP 校验，首次管理员凭据已轮换。
4. OCR 初次工具工作目录指向 SSH 用户目录、缺少 libGL；改用私有工作目录和独立提取的已校验 Ubuntu 库，随后三格式实际推理通过。
5. 初次健康探针错误使用本构建未提供的 actuator 地址；改为实际能力端点、数据库与 Redis 组合检查，五服务均健康。
6. 维护锁文件资源警告已修正；控制目录、维护原子写和独立后台日志目录已加固并复验。
