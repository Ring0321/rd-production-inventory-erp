## 已观察的结果

1. 新 `/pda` 独立壳不带 Web 后台侧栏/标签栏/设置菜单。生产、质检、仓管、叉车、销售、只读、管理员七账号分别看到生产工作台、质检工作台、仓管工作台、叉车工作台、销售查询工作台、查询工作台、查询工作台。
2. 生产默认加载真实 ACTIVE 任务；司机只有本人上架和装车两个组及目标/包数/重量/进度，不显示包码输入、扫码确认、修改位置或过账控件，且网络记录仅调用本人任务接口。
3. 司机装车默认采用服务器 `activeOnly=true`，当前样本从本人历史 5 项得到 1 项未完成任务。总数与服务器完整结果一致，传入另一司机 ID 不会越过本人限制；旧默认历史接口和已完成详情仍可回查。
4. 管理/只读默认查询，未得到新办理权限；质检和仓管只显示有既有权限的实际业务链接。当前链接标明 Web/查询，不冒充 D3/D4 专用移动办理页。
5. 未登录进入 `/pda` 正确返回登录并保留目标；刷新有效。只读账号退出、再次登录仍回原目标，静态 PDA 路由未被注销清理删掉。新独立生产页和司机页可以返回岗位首页。
6. 生产在岗位首页输入稳定二维码 URL 后进入本机 `/pkg` 身份页，携带 `workMode=pda`，原任务动作精确打开 `/pda/production?productionTaskId=6`。纸码内容不改，不导航到输入的外部 URL。
7. 七角色 × 1440/390/320 px 共 21 组合无文档/内容区域横向溢出；实际截图目测完成。入口/查询过程没有业务 POST/PUT，浏览器运行错误为 0。
8. 炉号从当前租户已登记产出/库存取候选，可按客户和型号搜索。样本客户 QR-TASK-A 精确选择 `TASK-6` 和原始层值“上层”；错误型号无候选。PDA 下拉实际选中，选择过程没有创建产出。
9. 现有层字典为空不补造厂炉编号；临时隔离字典测试证明只有启用且同租户条目可返回，停用和其他租户条目被排除，测试条目按唯一标记清理。历史原值不转换/覆写；客户端仍可输入真实新值。
10. 候选、任务和包件查询前后库存流水、包状态/版本/位置保持一致。切换客户/型号后晚响应不能串候选；失败可重试，现填炉号/层不会被查询改写。
