## 真实使用路径

1. 选择生产任务，读取确切任务成员；汇总包数、登记净重及来源生产记录。
2. 浏览生产任务、包装贴码、批次抽检、入库上架、库位库存、提货装车、出库复核和数字追溯八个阶段，各阶段列责任岗位、办理内容、形成记录及原业务入口。
3. 按当前环节、包号/型号/炉号/库位、炉层筛选包件；包件独立身份不变，未知重量不按零净重显示。
4. 选中包件后查看原二维码、登记状态、真实抽检覆盖/样包、原检验单、活动作业任务及实际流转时间线。
5. 打开原追溯关系图或精确登记 ID 的 3D 库位；装车/上架联动只读进入真实任务 `mode=view`，不自动进入扫码或过账。

叉车司机始终只接任务、搬运/摆放/装车及反馈异常。仓管员扫描、管理位置及最终入出库。没有新增司机扫码、库位维护或最终确认权限。
