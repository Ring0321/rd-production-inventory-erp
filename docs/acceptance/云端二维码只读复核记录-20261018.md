## 结论与边界

2026-10-18，按用户要求重新连接云端、检查二维码。普通连接在 8 秒超时；用户要求“再试一下”后，改用 12 秒期限重新连接，仍为 TCP 22 连接超时，尚未进入 SSH 认证阶段。**没有上传发行包，没有执行固定 admin 配置，没有修改云端文件或服务。** 不应把 HTTPS 能访问误写为 SSH 已恢复。
