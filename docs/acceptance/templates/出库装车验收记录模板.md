## 3. 前置条件

- [ ] 商务已提交有效提货单，客户与生产任务/销售订单一致。
- [ ] 库管能看到客户可用库存、包码、重量和当前库位。
- [ ] 待装货物均已质检合格、已入库且未被其他任务锁定。
- [ ] 一张提货单形成一张主装车任务，任务内直接列出各货位及货物明细。
- [ ] 叉车司机只能执行、扫码和反馈异常，不能自行换货或更改库存库位。
