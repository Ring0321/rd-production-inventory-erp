## 3. 前置条件

- [ ] 生产任务已绑定一个客户，货物包码已经生成。
- [ ] 质检结果为合格且已放行，未放行货物不可创建上架任务。
- [ ] 仓库、库区、库位状态真实可用，冻结或停用库位不可选择。
- [ ] 仓管员能查看库位地图、当前占用、剩余容量和待上架货物池。
- [ ] 仓管员和叉车司机账号权限相互隔离。
