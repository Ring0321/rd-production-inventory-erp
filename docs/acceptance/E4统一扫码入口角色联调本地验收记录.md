# E4 统一扫码入口角色联调本地验收记录

日期：2026-10-11。分支：`feature/warehouse-pda-next-phase`。范围为二维码统一入口、只读任务定位、源单跳转与默认角色菜单关联；这是隔离实例的技术联调，现场人员、终端和签字仍待验收。

## 1. 已实现的业务行为

同一个 `/pkg/{packageCode}` 地址继续提供公开查询及按权限加载的内部视图。内部角色通过 `GET /rd/package-unit/work-context/{packageCode}` 获取当前实际有效的上架/装车任务引用。这个接口只读，不登记扫码、不改库位，也不更新库存。身份来自认证会话，不能由调用者传入司机 ID。

仓管拥有任务查询权时可定位相关任务；司机仅有执行权时只返回分配给本人的任务。商务有提货单查询权时只得到对应提货单引用，不获得仓储任务列表。已完成/取消的任务不作为现场办理入口，历史查询仍需 E5 补齐。

包件已经被装车任务占用时，包状态可能仍是“在库”。入口依据真实任务优先显示扫码复核，避免按单一包状态再次引导派货。任务读取失败时提示刷新，不将失败当作“没有任务”继续引导新派单。

生产、最新质检、单包标签预览、装车任务与提货单页面消费精确记录 ID。司机装车页使用本人任务接口，不再循环查找前 20 个任务。包码库存和入库单的动态路由名称已对齐真实菜单；动作只链接当前用户已注册的路由。拥有管理员通配权限的用户可以正常读取内部视图。

同批包号支持直接点击，连续切换采用请求序号，迟到的查询响应不会覆盖新的包号、同批信息或任务关联。批次读取失败不再显示虚假的“0 包”。

## 2. 实际发现并修复的授权问题

使用真实登录的模拟生产账号验证时，后端允许包码查询，前端权限列表却缺少该项。根因为默认生产/质检角色有包码菜单而缺其仓库父目录；仓管有提货单查询而缺其订单父目录。前端过滤菜单后丢失了这些入口和权限展示。

已在 `rd_erp_clean.sql` 和 `rd_erp_upgrade_slim.sql` 同步补足：生产/质检角色的仓库目录，以及仓管角色的订单目录。只添加已有业务菜单的父目录关系，不新增业务操作权限，也不调整数据范围。隔离运行库通过既有角色菜单分配接口补齐父目录并刷新相关权限缓存；没有清空缓存服务或更改其他业务角色。

## 3. 样本和七账号结果

生产记录 6 对应两包已登记标签的本地示例；生产记录 7 对应 `LD20261011A0023`、`LD20261011A0024` 两包，各 1000 kg。客户、来源及备注均标记“二维码岗位本地验证（非现场数据）”。质检项目标记为接口验证，不是工厂检测结果；质检账号提交后由另一管理员账号审核。仓管制单、另一账号复核后过账；商务提供提货单，仓管派两包装车任务 2 给指定模拟司机。

对 `LD20261011A0023`，实际浏览器登录并观察：

| 账号角色 | 数据视图 | 当前入口及验证 |
| --- | --- | --- |
| 生产 | 内部视图 | 包码台账、补打、质检记录；补打直接打开该包预览；另一已贴标包可精准打开生产记录 6 |
| 质检 | 内部视图 | 包码台账、最新质检记录；准确打开该包的检验单及项目 |
| 仓管 | 内部视图 | 关联装车任务复核、提货单、包码、补打、质检、出库单和库存台账；进入任务 2 时带入代表包，无需重新找单 |
| 已分配司机 | 公开货物视图及本人任务引用 | 直接打开本人装车任务、货位和货物资料；装车页没有扫码确认或最终出库按钮 |
| 商务 | 公开货物视图及提货单引用 | 直接打开关联提货单；不返回仓储任务列表或库位等私有字段 |
| 未分配司机 | 公开货物视图 | 不提供该包的上架或装车办理入口；直接请求他人本人任务接口被拒绝 |
| 管理员 | 内部视图 | 通配权限正常显示内部数据；未作为该任务司机时不显示司机本人任务动作 |

上述角色按现有模板权限展示；本轮没有将旧模板的跨岗位写入权限宣称为已经完成 D1 统一。角色对应的是明确标记的测试账号，不是现场人员或签字。

## 4. 一致性与界面验证

查询前后快照包括包件状态、库位、库存批次、库存数量/重量与锁定量、任务状态/版本、任务明细扫码状态、库存流水数量和装车扫码记录数量。两包保持在 `LOC-A-01`，对应库存批次 2 包/2000 kg，锁定量 0；任务保持 `ASSIGNED`、已扫 0；两条入库流水不增加，装车扫码记录仍为 0。进入二维码、预览、源单和任务页不会隐式办理入出库。

未登录公开接口不包含客户、库位、生产记录号或质检单内部 ID。商务直接调用内部追溯接口被拒绝；未分配司机不能读取其他司机任务。管理员通配权限、同批点击、延迟响应下快速返回以及 390/320 px 追溯页无水平越界通过。生产、质检、仓管、司机和商务的目标页在桌面浏览器实际操作验证；没有把这些结果当作所有岗位 PDA 设备验收。
