## 三、风险判断

1. 如果未配置 DNS 和 HTTPS，现场打印出的二维码只能作为本地测试码，手机或客户侧扫码无法打开正式追溯页。
2. 如果正式域名未指向当前 ERP 追溯服务，标签提前批量打印后可能需要返工或重新贴标。
3. 如果公网访问未区分公开字段和内部字段，后续上线时可能出现客户看到内部库存、订单或人员信息的风险。

## 四、处理建议

1. 先保留当前自建 Digital Link 规则，即 `https://id.tjldsic.com/pkg/{packageCode}`，不改回国际 GS1 地址。
2. 正式批量打印标签前，必须完成一次“域名解析 -> HTTPS 访问 -> 未登录公开页 -> 登录内部页 -> PDA 连续扫码”的验收。
3. 在验收未完成前，所有标签打印和现场扫码记录只标记为本地技术验证，不写成线上投用完成。
4. 后续部署时建议用同一域名承载公开追溯页，内部操作仍走登录后的 ERP 权限控制。
