## 2. 实现边界

`RdWorkQueryMapper` 对计数、分页、重量和成员关联先应用服务器租户及删除/状态条件；全部为参数化 SELECT。`RdWorkQueryService` 使用只读 REPEATABLE_READ 事务，聚合与当前页使用同一快照；返回专用不可变 DTO，源版本来自原行。聚合没有可靠版本令牌时为 null，不伪造版本。

源失败返回 UNAVAILABLE，不能填零；缺重量或可靠覆盖时返回 PARTIAL，已知数量与待核指标分开。独立包件数、质检单数与重量单位不混用，金额/重量不经过前端浮点汇总。请求为多值白名单，重复/未知参数拒绝；服务端再次鉴权。司机即便叠加仓管或通配权限也不能获得全仓事实。

小垛前端先验证响应合同再显示结果，沿用原身份代次、取消和迟到响应丢弃。质检链接只允许当前可见原路由与受控 inspectionId，不接受任意 URL。无聊天持久化、新框架、迁移、任务调度或库存副本。

## 5. 遇到的问题与修复

1. 首次新 SQL 测试暴露 MyBatis 动态脚本里的 XML 运算符转义问题，修正后实际执行通过。
2. 真实 HTTP/页面联调发现 asOf 被应用默认序列化成数字。先补开启时间戳默认项的回归并得到失败，再局部固定 ISO 字符串；重建 JAR/重启独立本地后复验通过，未放宽前端校验。
