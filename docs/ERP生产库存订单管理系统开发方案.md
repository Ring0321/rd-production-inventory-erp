# 瑞鼎生产库存订单 ERP 开发方案

> 状态：已由 2026-07-11 深度瘦身方案取代。本文只保留业务范围说明，不再作为代码结构或实施依据。

## 产品范围

系统负责生产完成后的成品产量、入库、库存、订单匹配、调拨、出库和日报管理。核心追踪维度为货位、客户、型号、生产炉号、所在炉层和业务日期。

主要业务关系：

1. 炉层产量形成成品批次并办理入库。
2. 销售订单记录订单量、实际产额和差额。
3. 库存按货位、客户、型号、炉号和炉层核算数量与重量。
4. 当前库存不足时，可从其他库存调拨并计入订单履约。
5. 实际履约数量达到订单量后，订单自动完成。
6. 入库、出库、调拨和退货按业务日期形成日统计和库存流水。
