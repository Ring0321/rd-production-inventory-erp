## 路由与职责

- `PdaWorkspace`：`/pda`，已登录用户根据岗位看到当下有权限的实际操作入口和记录；无有效能力显示无权限，不授新业务权限。
- `PdaProduction`：`/pda/production`，现有生产录入页，任务参数照常消费。
- `PdaDriverPutaway`：`/pda/driver-putaway`；`PdaDriverLoading`：`/pda/driver-loading`，现有本人任务页，兼容任务 ID/包码输入，无扫码确认、位置调整或过账。
- 老 `/rd/production/production-entry`、司机旧页及所有 Web 路由保留，登录不强行改为 PDA；从专用 `/pda` 访问时保留返回目标。
- 质量和仓管显示既有实际业务入口，不装成已经完成了 D3/D4 专用页；管理/只读默认仅查询。
- 工作台扫码输入只提取包号，进入本机 `/pkg/{code}?workMode=pda`。稳定纸码 URL 不增加参数，不重新贴码。

## 数据候选接口

`GET /rd/production-output/furnace-options`、`/layer-options`：既有 `production-output:query` 权限，参数 `customerName, productModel, keyword, limit`。租户由登录上下文确定，最多 100；只读，不创建字典或改库存。炉层响应 `value,label,source`；字典候选用已配置名称，历史候选保持原值。无候选时允许输入，不暗示历史炉次就是本次正确炉次。
